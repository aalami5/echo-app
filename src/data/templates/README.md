# Operative Report Templates

Sample operative reports used by Echo's OR Dictation feature as reference templates.

## Structure

Each file contains templates organized by surgical category:

| File | Category | Procedures |
|------|----------|------------|
| `aortic.md` | Aortic | EVAR, TEVAR, Open AAA Repair |
| `carotid.md` | Carotid | CEA, Carotid Artery Stenting |
| `peripheral.md` | Peripheral Arterial | Fem-Pop Bypass, LE Angioplasty/Stenting, Thrombectomy/Embolectomy, Fem-Fem Bypass |
| `venous.md` | Venous | IVC Filter Placement, IVC Filter Retrieval |
| `dialysis-access.md` | Dialysis Access | AV Fistula (Radiocephalic, Brachiocephalic, Brachiobasilic), AV Graft, Access Thrombectomy |
| `other.md` | Other | BKA, AKA, Wound Debridement |

## How to Add a Sample Report

1. Open the relevant category file
2. Find the procedure section
3. Copy the template structure and fill in real (de-identified) operative details
4. Multiple samples per procedure are encouraged — they help Echo learn your style and variation

## Report Format

Each template follows a consistent structure:
- **Preoperative/Postoperative Diagnosis**
- **Procedure Performed**
- **Surgeon, Assistant, Anesthesia**
- **EBL, Fluids, Specimens, Drains, Complications**
- **Indications** — clinical reasoning
- **Description of Procedure** — detailed operative narrative
- **Findings** — key intraoperative findings
- **Disposition** — patient status at end of case

## Privacy Note

All sample reports should be **fully de-identified** — no patient names, MRNs, DOBs, or identifiable information.
